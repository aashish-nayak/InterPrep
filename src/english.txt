What is PHP?|PHP means PHP: Hypertext Preprocessor. It runs on the server to process requests, work with a database, and return HTML or JSON. Laravel provides structure and reusable tools around PHP.
What is a session?|HTTP requests do not remember each other. A session stores state, usually on the server, while the browser holds a session ID cookie. Expiry depends on configuration, not simply closing the browser.
Cookies vs sessions?|A cookie is stored in the browser and sent with matching requests. A session usually stores data on the server, identified by a cookie. Treat client cookies as untrusted and do not store plaintext secrets in them.
Variables vs constants?|A variable can be reassigned. A constant is a fixed named value declared with const or define(). Use a constant for a value that should not change during execution.
What are variable variables?|$message is a normal variable. $$message uses the value of $message as another variable's name. If $message is 'greeting', $$message reads $greeting. Prefer arrays when dynamic names make code confusing.
Is PHP case-sensitive?|Variable and constant names are case-sensitive. Function and class names are case-insensitive in PHP, but consistent spelling is essential, especially with filesystem-based autoloading.
What are PHP's data types?|Common types are int, float, string, bool, array, object, null and resource. Declarations also support types such as callable and iterable. Choose a type that expresses the meaning of the value.
How do you name a PHP variable?|Start with $, then a letter or underscore. Subsequent characters can include digits. Spaces are not allowed. $userName and $_count are valid; a name starting with a digit is not.
echo vs print?|Both produce output. echo accepts one or more arguments and has no return value. print accepts one argument and returns 1. Choose readable code rather than treating their tiny performance difference as an optimization.
Loose vs strict comparison?|== can convert types before comparing values. === compares both type and value. The number 10 loosely equals the string '10', but they are not strictly identical. Prefer strict comparisons when types matter.
isset(), empty(), array_key_exists()?|isset() is false for missing or null values. empty() is true for missing and false-like values, including 0 and '0'. array_key_exists() checks whether a key exists even when its value is null.
Post-increment vs pre-increment?|$x++ returns the old value, then increments. ++$x increments first and returns the new value. Starting at 5, $a = $x++ gives a=5 and x=6. A separate $b = ++$x then gives b=7 and x=7.
Type juggling vs casting?|Type juggling is automatic conversion based on context. Casting is an explicit conversion, such as (int) '42'. A numeric string can take part in arithmetic, but casting untrusted data is not a substitute for validation.
Does the string 'true' equal true?|With ==, comparing against a boolean converts the other operand to boolean. The nonempty string 'true' becomes true, so echo prints 1. With === the result is false because string and bool are different types.
What are references?|A reference lets two variable names access the same value. With $y =& $x, changing $y also changes the value seen through $x. Use this only when shared mutation is intentional.
What does unset do to a reference?|unset() removes a variable binding. If an alias still refers to the value, that alias remains usable. It does not delete a file; unlink() is the filesystem function.
break vs continue?|break exits the loop or switch. continue skips the rest of the current loop iteration. A numeric level can affect outer loops, so use it carefully and favor a clear control flow.
for vs foreach?|Use for when you need explicit control of a counter and stop condition. Use foreach to traverse arrays or iterables. Neither is universally faster; readability and measurements should guide the choice.
include vs require?|include reports a warning when a file cannot be loaded; require fails the execution unless the resulting error is handled. The _once versions avoid loading the same file twice. Prefer Composer autoloading for application classes.
unset vs unlink?|unset() removes a variable binding. unlink() attempts to delete a file. Before deleting a file, verify its path and the caller's permission. These functions solve completely different problems.
GET vs POST?|GET retrieves a representation and commonly uses URL parameters. POST submits data or initiates an operation with a request body. Hiding data from the URL does not make POST secure; use HTTPS.
PUT vs PATCH?|PUT normally replaces a resource and is intended to be idempotent. PATCH applies a partial change. Idempotent means repeating the same request has the same intended final effect.
What kinds of PHP errors exist?|Syntax errors prevent code from parsing. Warnings can allow execution to continue. Runtime Error and Exception objects implement Throwable. The exact category of a problem can differ across PHP versions.
How do you enable error reporting?|In development use error_reporting(E_ALL) and display_errors. In production disable display_errors, log securely, and keep Laravel APP_DEBUG=false so internal details are not exposed to users.
When do you use require in practice?|Use require for essential configuration or reusable code in small scripts. In Laravel, use Composer autoloading and namespaces for classes rather than maintaining manual include lists.
What PHP frameworks are available?|Examples include Laravel, Symfony, CodeIgniter, Yii, CakePHP and Slim. Laravel supplies routing, validation, an ORM, queues, caching, migrations and testing tools.
What does PEAR mean?|PEAR stands for PHP Extension and Application Repository. It is a historical system for reusable PHP components. Composer and Packagist are common in modern PHP dependency management.
urlencode vs urldecode?|urlencode encodes a query parameter value and represents spaces as +. urldecode reverses that encoding. Encode individual components, not an entire URL; rawurlencode uses percent encoding for spaces.
How do you remove line breaks?|Replace both carriage returns and newlines with str_replace(["\r", "\n"], '', $text). Choose a space instead of an empty string if words must remain separated.
How do you extract a file extension?|Use pathinfo with PATHINFO_EXTENSION for the extension and PATHINFO_FILENAME for the basename without it. This is clearer than manually splitting on dots. An extension alone does not establish file safety.
How do you remove HTML tags?|strip_tags removes tags but is not a complete HTML sanitizer. Escape output for its destination context. Removing tags and safely rendering untrusted content are different tasks.
What controls upload size?|PHP upload_max_filesize and post_max_size, web-server or proxy limits, and application validation all matter. Validate file type, size, authorization and destination. Do not assume a universal default limit.
How do you increase execution time?|max_execution_time and, where supported, set_time_limit control limits. Increasing a limit does not fix slow code. Move long exports and imports to background jobs and measure the bottleneck.
What are constructors and destructors?|__construct initializes an object when it is created. __destruct may perform cleanup when the object is destroyed. Avoid relying on destructor timing for critical business operations.
public, protected and private?|public is accessible outside the class. protected is accessible in the class and subclasses. private is accessible in the declaring class. Restrict access to protect the object's valid state.
What is inheritance?|A child class extends a parent and inherits accessible members. It can specialize behavior. Use inheritance for a genuine is-a relationship, not merely to reuse unrelated code.
Does PHP support multiple inheritance?|A class can extend only one class, but it can implement several interfaces and use several traits. Interfaces provide contracts; traits reuse implementation. They are not multiple parent classes.
What are traits?|Traits reuse methods across classes without making them part of one inheritance hierarchy. For example, unrelated models may share a reference-formatting method. Avoid hiding excessive dependencies inside traits.
Abstract class vs interface?|An interface defines a contract. An abstract class can also provide shared state and implementation. A class may implement multiple interfaces but extend only one class.
What are the four OOP pillars?|Encapsulation groups data and behavior. Abstraction hides unnecessary details. Inheritance specializes existing behavior. Polymorphism lets different implementations work through the same contract.
What are SOLID principles?|Single responsibility, open/closed, Liskov substitution, interface segregation and dependency inversion. For example, a checkout service can depend on a focused PaymentGateway interface rather than one specific provider.
What is dependency injection?|An object receives its collaborators instead of constructing them internally. Injecting a payment gateway into checkout makes it easier to replace the provider or use a test double. Laravel's container can resolve the dependency.
Composition vs inheritance?|Inheritance expresses is-a. Composition expresses has-a or delegates work to another object. A checkout service using a payment gateway is composition; it allows the gateway behavior to vary independently.
What design patterns are useful?|Strategy swaps algorithms, Factory creates objects, Adapter wraps an external interface, Observer reacts to events, and Decorator adds behavior. Add a pattern only when it solves a real problem.
What did PHP 8 introduce?|Examples include union types, named arguments, property promotion, match and the nullsafe operator. PHP 8.1 added enums, readonly properties, intersection types and Fibers; 8.2 added readonly classes. Explain a concrete use case.
What is the output of '5' + 2?|The output is 7. PHP treats the numeric string as a number in arithmetic. This is type juggling. Validate external input before relying on numeric conversion.
Is $x++ + ++$x safe to reason about?|Do not depend on evaluation order within this expression. PHP does not generally specify operand evaluation order. Split it into $a = $x++; $b = ++$x; echo $a + $b; to make the sequence explicit. Starting at 5, those separate statements print 12.
What does the reference sum print?|After $y =& $x and $y += 5, both names see 15. Adding $x and $y prints 30. This is shared storage, not two independent copies.
What happens when a reference is reassigned?|If $basket references $fruit, assigning 'banana' to $basket changes the value seen by $fruit too. Both names refer to the same value.
Can an alias survive unset?|Yes. Removing the original variable name does not remove the alias. The alias can still print 'Hello'. Think of removing one label rather than destroying all access to the value.
How do you find the least frequent number?|Count values with array_count_values, sort frequencies with asort to preserve keys, then read array_key_first. Define tie behavior and handle an empty input. In the supplied example, 6 appears only once.
How do you count each vowel?|Lowercase the text, initialize a counter for each vowel, then iterate through characters and increment matching counters. Keeping all five counters also shows vowels that occur zero times. This example assumes ASCII text.
How do you turn key-value pairs into rows?|Iterate with foreach ($data as $key => $value) and append [$key, $value] to a new array. Each original entry becomes one two-element row.
How do you add hours, minutes and seconds?|Convert hours to seconds by multiplying by 3600, minutes by 60, then add the seconds to a timestamp. Use DateTimeImmutable or Carbon when calendar and timezone behavior matters.
How do you check a palindrome?|Normalize case and remove the characters your rules ignore, then compare the text with its reverse. 'Madam' becomes 'madam' and matches. The supplied regex and strrev example is ASCII-oriented.
How do you reverse a string?|strrev reverses bytes and works for simple ASCII strings. 'Laravel' becomes 'levaraL'. Use a multibyte or grapheme-aware approach for Unicode text.
How do you find duplicate values?|Count occurrences, keep counts greater than one, then take the keys. For [1,2,2,3,4,4], the duplicated values are 2 and 4. array_count_values supports integer and string values.
How do you count words?|str_word_count works for basic English-like text. 'PHP makes web apps' contains four words. Use a Unicode-aware tokenizer when the application's language rules require it.
How do you swap two variables?|Use [$a, $b] = [$b, $a]. A temporary variable is equally valid. Choose readability instead of arithmetic tricks that may overflow or obscure intent.
How do you sort an array?|sort and rsort reorder values ascending and descending and reindex numeric keys. asort and arsort preserve key associations. Choose the function based on whether keys carry meaning.
Explain the Laravel request lifecycle.|A request enters public/index.php, loads Composer and bootstraps Laravel. Middleware runs, a route is matched, and the controller or service performs work. The response passes back through middleware to the client. Internal details depend on Laravel version.
What is the service container?|The container resolves classes and injects their dependencies. A controller can request a service in its constructor instead of constructing every dependency manually. Bind interfaces to concrete implementations where needed.
bind vs singleton?|bind usually resolves a fresh instance. singleton reuses the same resolved instance within the container. Be careful with mutable request-specific state in long-running workers.
What does a service provider do?|A provider registers and boots application services. Put container bindings in register(). Put setup that needs registered services in boot(). This keeps application initialization organized.
What is middleware?|Middleware checks or changes requests before the controller and can process the response afterwards. Authentication, rate limiting, tenant identification and request logging are common uses.
Authentication vs authorization?|Authentication establishes who the caller is. Authorization checks what the caller may do. Logging in must not automatically permit editing another user's record; check ownership or a policy.
Sanctum vs Passport?|Sanctum supports SPA cookie authentication and simple API tokens. Passport supplies an OAuth 2.0 authorization server. Choose based on the integration's requirements rather than adding OAuth complexity by default.
What are Eloquent relationships?|Examples include hasOne, hasMany, belongsTo, belongsToMany, hasManyThrough and polymorphic relationships. Also consider foreign keys, indexes, deletion behavior and how related records are loaded.
What is the N+1 query problem?|One query loads parent records, then accessing a relation triggers a query for each parent. With 20 orders, that can mean 21 queries. Eager loading the user relation can reduce this to two for a typical belongsTo relation. Verify using query logs.
with(), load() and whereHas()?|with loads relations as part of the initial retrieval workflow. load loads them after models have been retrieved. whereHas filters parents using a condition on related records; it does not itself eager-load them.
find(), first(), get() and value()?|find looks up a primary key. first returns the first matching model or null. get returns a collection. value returns one column from the first matching record. Select the shape your caller needs.
create(), save(), update() and insert()?|create mass-assigns a new model; save inserts or updates an instance. update behaves differently on a model and a query. Query-builder insert writes rows without returning an Eloquent model. Bulk queries do not fire individual model events.
What is mass assignment?|Passing every request field to a model can let a caller set sensitive attributes. Validate an explicit set of fields and configure fillable or guarded. Validation and permission checks are both needed.
What is a Form Request?|A Form Request groups validation and authorization outside the controller. It makes input rules easier to test and reuse while letting the controller focus on the use case.
How do database transactions work?|DB::transaction commits successful database work and rolls back if an exception escapes the callback. It does not undo an external payment API call. Design external effects and retries separately.
What are jobs and queues?|Queues move work such as emails, exports and imports outside the HTTP request. A worker processes dispatched jobs. Plan retries, backoff, timeouts, failed-job handling and idempotency.
Events, listeners and observers?|An event announces that something happened. A listener reacts to it. An observer groups handlers for model lifecycle events. Consider transaction commit timing and reliable delivery for important workflows.
What is caching?|Caching reuses a stored result to avoid repeated queries or computation. Cache::remember returns a cached value or calculates and stores it. Design keys, expiry and invalidation so stale data is acceptable.
What is an API Resource?|A Resource transforms a model into an explicit public JSON representation. It separates database structure from the API contract and helps avoid accidental exposure of sensitive fields.
Soft delete vs hard delete?|A hard delete removes the row. A soft delete sets deleted_at and normally hides the row from Eloquent queries. Consider restoration, retention requirements and unique constraints.
How would you secure a Laravel API?|Use authentication, per-resource authorization, input validation, rate limits and HTTPS. Protect secrets, validate uploads, use bound SQL parameters, and avoid exposing private fields or sensitive error details.
How do you investigate a slow app?|Measure endpoint latency, query counts, execution plans, indexes, external calls and response sizes. Apply a targeted fix, such as eager loading or caching, then measure again. Do not guess at the bottleneck.
How do you test Laravel?|Unit tests isolate business logic. Feature tests exercise HTTP behavior. Integration tests check collaborating components. Factories, actingAs, HTTP assertions and queue or mail fakes help verify behavior and failure paths.
WHERE vs HAVING?|WHERE filters rows before grouping. HAVING filters grouped or aggregated results. For example, filter active employees with WHERE, then keep departments with more than five employees using HAVING COUNT(*) > 5.
INNER JOIN vs LEFT JOIN?|INNER JOIN returns matches from both sides. LEFT JOIN keeps every left-side row and fills right-side columns with null when no match exists. Check how later WHERE conditions affect unmatched rows.
UNION vs UNION ALL?|UNION removes duplicate result rows. UNION ALL preserves duplicates and avoids deduplication work. Use ALL when duplicate rows are valid or impossible by design.
DELETE, TRUNCATE and DROP?|DELETE removes rows and supports WHERE. TRUNCATE removes all rows and in MySQL is a DDL operation that generally implicitly commits. DROP removes the table itself. They are not interchangeable.
What is an index?|An index helps locate rows without scanning everything. It costs storage and makes writes more expensive. Choose indexes for actual query patterns and verify the execution plan.
Why does composite index order matter?|An index on (customer_id, status) can generally help with customer_id alone or both fields. A status-only lookup may not benefit in the same way. This is the leftmost-prefix principle.
Clustered vs secondary indexes?|In InnoDB, clustered-index leaf pages contain row data, usually ordered by the primary key. Secondary entries contain their indexed columns plus the primary key; retrieving other columns can require another lookup.
What is normalization?|Normalization organizes tables to reduce duplication and update anomalies. 1NF uses atomic values; 2NF removes partial-key dependencies; 3NF avoids inappropriate transitive dependencies. Denormalize only for a measured need.
What does ACID mean?|Atomicity: all or none. Consistency: preserve constraints and invariants. Isolation: control concurrent transactions. Durability: committed data persists according to database guarantees.
What is a deadlock?|Transactions wait for locks held by one another. Use a consistent lock order, short transactions and suitable indexes. Retry recognized deadlock failures only when repeating the operation is safe.
How do COUNT variants differ?|COUNT(*) counts rows. COUNT(column) counts non-null values. COUNT(DISTINCT column) counts distinct non-null values. Null handling often explains unexpected differences.
GROUP BY vs DISTINCT?|DISTINCT removes duplicate result rows. GROUP BY forms groups, commonly for COUNT, SUM or AVG. Choose based on whether you need unique rows or an aggregate per group.
Find the second-highest distinct salary.|Select the maximum salary strictly below the overall maximum. Repeated highest salaries are excluded together. If there is no second distinct value, the result is null.
How do you find duplicate emails?|Group non-null emails and keep groups with COUNT(*) > 1. Clean up duplicates, then consider a suitable unique constraint to prevent recurrence. Decide the desired case and collation behavior.
Find customers with no orders.|Use NOT EXISTS with a correlated orders query. A LEFT JOIN followed by a null check on a non-nullable order key is another option. Both express absence of matching orders.
Offset vs keyset pagination?|Offset skips a specified number of rows and can become expensive on deep pages. Keyset continues after a previously seen key. Use stable ordering and a unique tie-breaker for reliable cursors.
What does EXPLAIN show?|EXPLAIN shows the query plan, such as access methods, chosen indexes and estimated row counts. EXPLAIN ANALYZE actually runs the query on supported versions, so consider its effects before using it in production.
Subqueries, CTEs and window functions?|A subquery nests a query. A CTE names a result within a statement. A window function calculates across related rows while preserving individual rows, such as ROW_NUMBER per customer ordered by amount.
How would you integrate an insurance provider API?|Validate and authorize at the application boundary. Use a service for the workflow and an adapter for HTTP, payload mapping, signatures and errors. Track operation IDs, status, retries and reconciliation; keep credentials in secure configuration.
What is JWS signing?|JSON Web Signature protects integrity and allows verification of the signer. Follow the provider's specified algorithms, headers, payload and keys. A signature does not encrypt the payload or make it secret.
How would you build a large Excel export?|Dispatch a background job, process records in chunks or with a cursor, store the result and expose an authorized download. Track status and handle memory limits, failure and temporary-file cleanup.
How do you prevent duplicate payments?|Use idempotency keys, suitable unique constraints and transaction or locking rules for concurrency. Reconcile uncertain outcomes with the provider. A timeout does not prove the payment failed.
Why does an API work locally but fail in production?|Compare deployed versions, configuration, secrets, extensions, permissions, migrations, network access and workers. Use correlation IDs and sanitized logs to isolate the failing layer, then add a regression test.
How would you design a realtime feature?|Persist the authoritative state before broadcasting. Authorize private channels and handle reconnects, duplicates, ordering and missed messages. The browser's copy is not the source of truth.
How do you investigate slow SQL?|Identify the slow query, inspect its plan, rows examined, joins, filters and sorts. Test a targeted query or index change on representative data and compare latency after deployment.
How do you handle third-party API failures?|Set timeouts, validate responses and use safe retries with backoff. Track correlation IDs, idempotency and reconciliation. Consider circuit breaking where useful. Never blindly retry a non-idempotent operation.
How do you maintain senior-level code quality?|Use clear boundaries, focused classes, dependency injection, validation, reviews and automated tests. Add useful logs, safe configuration, compatible migrations and measurable monitoring. Abstract only to solve a real problem.
Print a solid square.|The outer loop creates rows. The inner loop prints n stars on each row. A newline finishes the row. For n=4, there are four rows of four stars.
Print a right-angled triangle.|The outer loop chooses row i. The inner loop prints i stars. Row lengths grow from 1 to n; each completed row ends with a newline.
Print an inverted triangle.|Start the outer counter at n and decrement to 1. Print i stars on each row. The triangle gets one star shorter each time.
Print a number triangle.|For row i, print the inner counter j from 1 through i. Reset j at the start of every row. The result begins with 1, then 12, then 123.
Print repeated row numbers.|Print i rather than j in the inner loop. Row 1 contains 1, row 2 contains 22, and row 3 contains 333. The outer counter determines the repeated digit.
Print Floyd's triangle.|Keep a number counter outside both loops. Print it and increment after each value. Because it is not reset between rows, the sequence continues as 1, then 2 3, then 4 5 6.
Print a pyramid.|For row i, print n-i spaces followed by 2*i-1 stars. Spaces decrease while star counts increase through odd numbers. Preserve leading spaces when displaying the output.
Print an inverted pyramid.|Use the pyramid rule but iterate i from n down to 1. Star counts shrink and leading spaces grow. The widest row appears first.
Print a diamond.|Print the upper pyramid, then its inverted lower half. Start the lower half at n-1 so the widest row is not duplicated.
Print a hollow square.|Print a star when the row or column is at the first or last boundary. Print a space everywhere else. Both loops still traverse the whole square.
Print an alphabet triangle.|Use chr(65 + j) to generate A, B, C and so on. Each row prints one additional letter. This simple ASCII example is intended for the A-Z range.
Print a shrinking number triangle.|Count the outer row length down from n to 1, while the inner loop still prints numbers in ascending order. The result is 1234, then 123, then 12, then 1.
Print alternating ones and zeros.|Check whether i+j is even. Print 1 for even and 0 for odd. The parity changes in both directions, creating the alternating pattern.
Print Pascal's triangle.|Each row starts with 1. Compute the next value with value*(i-j)/(j+1), using integer division for this recurrence. Pad the row with spaces. Large rows can overflow fixed-size integers.
Turn the triangle into a function.|Accept a positive integer size and reject values below 1. Print str_repeat('*', i) for each row. A function makes the pattern reusable and gives input validation a clear home.
